75Play

v2.0.1 · 長安 CS75 Plus 2020 · SoftAP

把 iPhone 的 CarPlay
無線投到車機。

開源無線 CarPlay 接收端。Wi‑Fi Direct / 車機熱點 / 區域網路，全螢幕沉浸，無須越獄、轉接盒或帳號。

請安裝在車機上。非 Apple 認證；與 Apple / 長安無隸屬關係。

專為這台車做的

  • 僅無線三種方式：Wi‑Fi Direct（預設）、車機熱點（SoftAP）、區域網路。本車無 TUN，已移除 USB 有線。
  • 全螢幕沉浸寬螢幕適配；CarPlay 內開啟車機應用；懸浮小白點返回。
  • 玻璃雙主題 UI主頁與設定依駕駛目標分組。
  • 一鍵連接切換 Wi‑Fi Direct / 車機熱點會自動準備網路；區域網路連上 Wi‑Fi 後自動連接 CarPlay。
  • 多語言簡 / 繁中文、英文、阿拉伯語、西班牙語、俄語、烏克蘭語。

僅支援長安 CS75 Plus 2020（OS_S311-WT · API 19 · armeabi-v7a）。

裝上車機並連線

  1. 1停車後從 GitHub Releases 下載 APK（USB 或 adb）。
  2. 2解除安裝其他簽章的 75Play，再用車機檔案管理員安裝。
  3. 3開啟 75Play，iPhone 保持藍牙開啟。Wi‑Fi Direct / 車機熱點：切換方式會自動開 Wi‑Fi 或設定熱點，再點「連接 CarPlay」。區域網路：選網填密，連上 Wi‑Fi 後自動進入 CarPlay。
  4. 4在 iPhone 上允許 CarPlay。

日常不需要 ADB。三種方式細節見安裝說明。 完整安裝說明

版本歷史

v2.0.1

  • 壳层布局：贴边导航轨和顶栏（页名、连接状态、时钟）。主页不再上下叠卡，连接与车机应用左右铺满。
  • 应用列表：主页和 CarPlay 里的隐藏、排序共用同一份记录。
  • 开发者终端：关于页入口保留，打开前需确认。
  • 车机热点：启用收成一处，壳、开机和连接不再各写一套。
  • 虚报 Android 版本：系统仍是 4.4.2、但接口版本被报高时，画面、方控、麦克风、连接通知和检查更新留在 KitKat 可用的接口上。
  • 画面：首帧继续补发解码参数，输入缓冲保持 3MB；硬解失败时改用软解。解码缓冲按帧复用，减轻 30 fps 时的停顿。
  • Wi-Fi Direct：版本被报高时仍走车机上的旧通道，不再误入 Android 8 才有的热点接口。
  • 壳层：主页、设置、关于来回切换时保留滚动位置和局域网列表。应用图标按下有反馈。Wi-Fi Direct 频道名称跟随当前语言。

v2.0.0

  • 玻璃双主题 UI：主页与设置重新设计、按司机目标分组排版。
  • 无线 CarPlay：内置 MFi 认证密钥；Wi‑Fi Direct / 车机热点（SoftAP）/ 局域网（Existing Wi‑Fi）；无需越狱、转接盒或账号。因车机无 TUN，已移除 USB 有线。
  • 一键连接：简化连接流程。
  • 全屏沉浸：CarPlay 铺满宽屏，默认 30 fps；CarPlay 内打开 / 管理车机应用；悬浮小白点返回。
  • 多语言：简 / 繁中文、英文、阿拉伯语、西班牙语、俄语、乌克兰语。
  • 安卓终端（实验性）、系统设置入口（#518200#）。

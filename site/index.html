75Play

v2.0.0 · 长安 CS75 Plus 2020 · SoftAP

把 iPhone 的 CarPlay
无线投到车机。

开源无线 CarPlay 接收端。Wi‑Fi Direct / 车机热点 / 局域网，全屏沉浸，无需越狱、转接盒或账号。

请安装在车机上。非 Apple 认证；与 Apple / 长安无隶属关系。

专为这台车做的

  • 无线-only三种方式：Wi‑Fi Direct（默认）、车机热点（SoftAP）、局域网。本车无 TUN，已移除 USB 有线。
  • 全屏沉浸宽屏适配；CarPlay 内打开车机应用；悬浮小白点一键返回。
  • 玻璃双主题 UI主页与设置按司机目标分组，昼夜主题一致。
  • 一键连接切换 Wi‑Fi Direct / 车机热点会自动准备网络；局域网连上 Wi‑Fi 后自动连接 CarPlay。
  • 多语言简 / 繁中文、英文、阿拉伯语、西班牙语、俄语、乌克兰语。

仅支持长安 CS75 Plus 2020（OS_S311-WT · API 19 · armeabi-v7a）。

装上车机并连接

  1. 1停车后从 GitHub Releases 下载 APK（U 盘或 adb）。
  2. 2卸载其他签名的 75Play，再用车机文件管理器安装。
  3. 3打开 75Play，iPhone 保持蓝牙开启。Wi‑Fi Direct / 车机热点：切换方式会自动开 Wi‑Fi 或配置热点，再点「连接 CarPlay」。局域网：选网填密，连上 Wi‑Fi 后自动进 CarPlay。
  4. 4在 iPhone 上允许 CarPlay。

日常无需 ADB。三种方式细节见安装说明。 完整安装说明

版本历史

v2.0.0

  • 玻璃双主题 UI：主页与设置重新设计、按司机目标分组排版。
  • 无线 CarPlay：内置 MFi 认证密钥；Wi‑Fi Direct / 车机热点（SoftAP）/ 局域网（Existing Wi‑Fi）；无需越狱、转接盒或账号。因车机无 TUN，已移除 USB 有线。
  • 一键连接：简化连接流程。
  • 全屏沉浸：CarPlay 铺满宽屏，默认 30 fps；CarPlay 内打开 / 管理车机应用；悬浮小白点返回。
  • 多语言：简 / 繁中文、英文、阿拉伯语、西班牙语、俄语、乌克兰语。
  • 安卓终端（实验性）、系统设置入口（#518200#）。
  • 启动提速：减少黑屏 / 闪启动页；品牌页首帧与背景图异步解码。
  • 电话与导航无声。

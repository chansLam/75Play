75Play

v2.0.1 · Changan CS75 Plus 2020 · SoftAP

Wireless CarPlay
for your CS75 Plus.

Open-source wireless CarPlay receiver. Wi‑Fi Direct / car hotspot / existing Wi‑Fi (LAN), immersive display — no jailbreak, dongle, or account.

Download APK Install steps Changelog

Mirror 1 · Mirror 2

Install on the head unit. Not Apple-certified; not affiliated with Apple or Changan.

Built for this car

  • Wireless-onlyThree modes: Wi‑Fi Direct (default), car hotspot (SoftAP), and existing Wi‑Fi / LAN. USB wired removed — this unit has no TUN.
  • Immersive displayWide-screen layout; launch head-unit apps from CarPlay; floating ball to return.
  • Glass dual-theme UIHome and settings grouped by driver goals.
  • One-tap connectSwitching to Wi‑Fi Direct or car hotspot prepares the link automatically; LAN starts CarPlay after Wi‑Fi connects.
  • Languageszh-Hans / zh-Hant / en / ar / es / ru / uk.

Changan CS75 Plus 2020 only (OS_S311-WT · API 19 · armeabi-v7a).

Install and connect

  1. 1While parked, download the APK from GitHub Releases (USB or adb).
  2. 2Uninstall any differently signed 75Play, then install with the head-unit file manager.
  3. 3Open 75Play; keep Bluetooth on. Wi‑Fi Direct / car hotspot: switching auto-enables Wi‑Fi or configures the hotspot — then tap Connect CarPlay. LAN: pick Wi‑Fi and enter the password; CarPlay starts automatically after Wi‑Fi joins.
  4. 4Allow CarPlay on the iPhone.

ADB is optional. See the install guide for mode details. Full install guide

Changelog

v2.0.1

  • 壳层布局：贴边导航轨和顶栏（页名、连接状态、时钟）。主页不再上下叠卡，连接与车机应用左右铺满。
  • 应用列表：主页和 CarPlay 里的隐藏、排序共用同一份记录。
  • 开发者终端：关于页入口保留，打开前需确认。
  • 车机热点：启用收成一处，壳、开机和连接不再各写一套。
  • 虚报 Android 版本：系统仍是 4.4.2、但接口版本被报高时，画面、方控、麦克风、连接通知和检查更新留在 KitKat 可用的接口上。
  • 画面：首帧继续补发解码参数，输入缓冲保持 3MB；硬解失败时改用软解。解码缓冲按帧复用，减轻 30 fps 时的停顿。
  • Wi-Fi Direct：版本被报高时仍走车机上的旧通道，不再误入 Android 8 才有的热点接口。
  • 壳层：主页、设置、关于来回切换时保留滚动位置和局域网列表。应用图标按下有反馈。Wi-Fi Direct 频道名称跟随当前语言。

v2.0.0

  • 玻璃双主题 UI：主页与设置重新设计、按司机目标分组排版。
  • 无线 CarPlay：内置 MFi 认证密钥；Wi‑Fi Direct / 车机热点（SoftAP）/ 局域网（Existing Wi‑Fi）；无需越狱、转接盒或账号。因车机无 TUN，已移除 USB 有线。
  • 一键连接：简化连接流程。
  • 全屏沉浸：CarPlay 铺满宽屏，默认 30 fps；CarPlay 内打开 / 管理车机应用；悬浮小白点返回。
  • 多语言：简 / 繁中文、英文、阿拉伯语、西班牙语、俄语、乌克兰语。
  • 安卓终端（实验性）、系统设置入口（#518200#）。

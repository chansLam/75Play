Сделано для этой машины

  • Только беспроводнойТри режима: Wi‑Fi Direct (по умолчанию), точка доступа авто (SoftAP) и существующая Wi‑Fi / LAN. USB убран — нет TUN.
  • Иммерсивный экранШирокий дисплей; приложения ГУ из CarPlay; плавающий шарик.
  • Стеклянный UIГлавная и настройки по целям водителя.
  • Быстрое подключениеПереключение на Wi‑Fi Direct или точку доступа готовит связь само; в LAN CarPlay стартует после подключения к Wi‑Fi.
  • Языкиzh-Hans / zh-Hant / en / ar / es / ru / uk.

Только Changan CS75 Plus 2020 (OS_S311-WT · API 19 · armeabi-v7a).

Установка и подключение

  1. 1На стоянке скачайте APK из GitHub Releases.
  2. 2Удалите 75Play с другой подписью и установите этот APK.
  3. 3Откройте 75Play; Bluetooth включён. Wi‑Fi Direct / точка доступа: переключение само готовит сеть — затем нажмите «Подключить CarPlay». LAN: выберите Wi‑Fi и пароль; CarPlay запустится автоматически после подключения.
  4. 4Разрешите CarPlay на iPhone.

ADB не обязателен. Подробности режимов — в инструкции по установке. Полная инструкция

История версий

v2.0.1

  • 壳层布局：贴边导航轨和顶栏（页名、连接状态、时钟）。主页不再上下叠卡，连接与车机应用左右铺满。
  • 应用列表：主页和 CarPlay 里的隐藏、排序共用同一份记录。
  • 开发者终端：关于页入口保留，打开前需确认。
  • 车机热点：启用收成一处，壳、开机和连接不再各写一套。
  • 虚报 Android 版本：系统仍是 4.4.2、但接口版本被报高时，画面、方控、麦克风、连接通知和检查更新留在 KitKat 可用的接口上。
  • 画面：首帧继续补发解码参数，输入缓冲保持 3MB；硬解失败时改用软解。解码缓冲按帧复用，减轻 30 fps 时的停顿。
  • Wi-Fi Direct：版本被报高时仍走车机上的旧通道，不再误入 Android 8 才有的热点接口。
  • 壳层：主页、设置、关于来回切换时保留滚动位置和局域网列表。应用图标按下有反馈。Wi-Fi Direct 频道名称跟随当前语言。

v2.0.0

  • 玻璃双主题 UI：主页与设置重新设计、按司机目标分组排版。
  • 无线 CarPlay：内置 MFi 认证密钥；Wi‑Fi Direct / 车机热点（SoftAP）/ 局域网（Existing Wi‑Fi）；无需越狱、转接盒或账号。因车机无 TUN，已移除 USB 有线。
  • 一键连接：简化连接流程。
  • 全屏沉浸：CarPlay 铺满宽屏，默认 30 fps；CarPlay 内打开 / 管理车机应用；悬浮小白点返回。
  • 多语言：简 / 繁中文、英文、阿拉伯语、西班牙语、俄语、乌克兰语。
  • 安卓终端（实验性）、系统设置入口（#518200#）。

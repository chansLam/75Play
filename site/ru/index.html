75Play

v2.0.4 · Changan CS75 Plus 2020 · Wi‑Fi Direct

Беспроводной CarPlay
для вашего CS75 Plus.

Открытый беспроводной клиент CarPlay. Wi‑Fi Direct / точка доступа авто / существующая Wi‑Fi (LAN), иммерсивный экран — без джейлбрейка, адаптера и аккаунта.

Зеркало 1 · Зеркало 2

Устанавливайте на ГУ. Не сертифицировано Apple; не связано с Apple или Changan.

Сделано для этой машины

  • Три беспроводных режимаWi‑Fi Direct по умолчанию и только IPv4. Точка доступа авто и существующая Wi‑Fi остаются. Старый выбор LocalOnly считается точкой доступа авто. При сбое Direct сеть сбрасывается один раз. USB нет — нет TUN.
  • Кнопки руляПока CarPlay на переднем плане: голос будит Siri, предыдущий / следующий трек, ответ / завершение. Громкость и SRC остаются у машины. Тест кнопок выключается, когда CarPlay заканчивается или приложение падает.
  • Картинка на весь экранВсегда на весь экран, SurfaceView, H.264. Кадры 15 / 30 / 45 / 60, по умолчанию 30. Средний и малый размер могут показать умное масштабирование на iPhone. Свайп тремя пальцами возвращает в 75Play.
  • Настройки в оболочкеЭкран и звук и «О программе» — три колонки, их не правят поверх картинки CarPlay. Скрытые приложения и порядок общие с CarPlay.
  • Языкиzh-Hans / zh-Hant / en / ar / es / ru / uk.

Только Changan CS75 Plus 2020 (OS_S311-WT · API 19 · armeabi-v7a).

Установка и подключение

  1. 1На стоянке скачайте APK из GitHub Releases.
  2. 2Удалите 75Play с другой подписью и установите этот APK.
  3. 3Откройте 75Play; Bluetooth включён. Wi‑Fi Direct / точка доступа: переключение само готовит сеть — затем нажмите «Подключить CarPlay». LAN: выберите Wi‑Fi и пароль; CarPlay запустится автоматически после подключения.
  4. 4Разрешите CarPlay на iPhone.

ADB не обязателен. Подробности режимов — в инструкции по установке. Полная инструкция

История версий

v2.0.4

  • 导航投仪表盘：新增 NaviClusterBroadcast，订阅 CarPlay 导航快照，把导航启停（2000）与转向（2002）广播发给系统 RunService.TencentNaviReceiver，经 CAN 转发到仪表盘 MCU，渲染转向箭头 / 限速 / 道路名。抛弃 BYD 中间层，rg_on_direction 由 Apple RouteGuidanceManeuverType 直连腾讯 turnType 值域；环岛增强（苹果 6/7/28–46 → 腾讯环路 93 右出口）；导航开始清 MCU 限速、路由结束清箭头残留；修正 currentRoad 与下一转弯道路名语义。配套把 BydManeuverCodes 改为公开对象并在 CarPlay 宿主接入。
  • 顶部温度栏：新增 CoagentAcBridge 反射绑定车机 coagent.ac 空调服务（注册回调 tx19、回调推送 tx7、开机拉快照 tx27）+ TemperatureBar 全局顶部浮层，显示室外 / 车内 / 设定温度；设置 → 显示 新增「顶部温度栏」开关（默认开启）。
  • 顶部温度栏「设定」无值：固件只在温度变化时推送 onACTempChanged，启动时没有拉取初始快照，导致驾驶员 / 副驾「设定」温度一直是 --。现在注册回调后调用 refreshSnapshot() 一次性拉取 AirConditionInfo；因固件字段序列化方式（writeInt/writeString/布尔字节数）未公开，改为自动解码多种候选布局并应用首个四温度均合理且非全零的结果，原始回复字节与各候选解析结果均写入诊断日志，避免错误布局覆盖回调实时值。
  • 仪表盘导航方向 / 残留：修正 rg_on_direction 值域导致的转向方向反、路由结束箭头残留、当前与下一道路名混淆。
  • 应用列表自动刷新：装 / 卸 / 升级 APK 后主页车机应用网格不再停留旧状态。新增 AppInstallWatcher 监听系统包变更广播（ACTION_PACKAGE_ADDED / REMOVED / REPLACED，含外部存储事件），收到后失效枚举缓存并立即重绘网格；HomeAppGrid 新增 refreshAfterPackageChange()，由 FragmentHome 生命周期接入，跟随页面可见性启停避免接收器泄漏。
  • 主题：跟随系统改回读取系统 uiMode 夜间位；环境光改用 coagent.settings 亮度传感器（MCU 上报屏幕亮度 0..255），夜间阈值改为亮度 0..255、默认 80。
  • 死代码清理：删除一批生产代码零引用、仅测试引用的类及其对应测试（MFI 诊断、P2P 启动/归属/诊断、热点策略、Wi‑Fi Direct 遗留通道、SafeArea 编辑器、连接设置分区等）；LegacyHotspotRadio 精简内部仅测试引用的 Settled；恢复被误判为死代码的 SidePanelSettings 与 P2pResetRequiredException。

v2.0.3

  • CarPlay 前台方控音量 / 静音：改直调车机 coagent.settings 服务（IBinder.transact），补 KEY_SWC_VOL_INC/DEC 键名映射，MUTE 键在固件以 NONE 态广播时同样触发静音切换。实车验证音量加减、静音均已生效。
  • 方控：方向盘按键在 CarPlay 画面前台时由按键测试接管。语音唤醒 Siri，上一曲 / 下一曲，电话接听 / 挂断。音量和 SRC 交还车机。
  • 悬浮球：只负责回到壳层，默认关闭。方控学习、Root 注入和方控设置入口已去掉。
  • 显示：帧率可选 15 / 30 / 45 / 60，默认仍是 30，改动需要重连。画面固定全屏，固定走 SurfaceView 和 H.264。
  • 智能缩放：连接时按所选物理尺寸上报。中、小尺寸让 iPhone 显示「智能缩放显示」，大尺寸不显示。KitKat 上报的帧率至少为 60，避免 iOS 把这一项藏起来。实际解码仍用设置里的帧率。
  • 主题：跟随系统时读取车机大灯主题（coagent_theme），不再只看 Android 的 uiMode。
  • 设置：显示与音频改成三列。去掉界面大小、左侧 Dock 内边距、自适应 PiP、隐藏顶栏 / 底栏、Root 全局隐藏导航栏、HEVC、画面调整、直接 SurfaceView、高级通道映射、音频焦点和通话语音过滤。旧的顶栏 / 底栏开关不再读取，画面保持全屏。若以前开过 Root 隐藏导航栏，启动时把系统属性改回，不重启显示服务。
  • 连接：Wi‑Fi Direct 只使用 IPv4，并只走 KitKat 的组网。以前选过的 LocalOnly 热点会当成车机热点。直连失败时先自动重置一次，再次失败才提示。

v2.0.2

  • 壳层：面板不再描边。浅色正文为纯黑，浅色玻璃更透，顶栏与左侧导航连在一起。暗色未连接按钮改为蓝色圆盘。
  • 连接：连接中重新显示准备、网络、手机、握手、画面。
  • 音量：导航提示播放时，音量键改调导航，结束后回到媒体。导航音轨打不开时不再退回媒体音轨。
  • 方控：媒体键在按下时发给 iPhone。已有会话时，壳层也能把方控转进去。
  • 悬浮球：默认停在左下，避开右侧应用栏。
  • 画面：ChaCha20-Poly1305 用本地库解密，帧缓冲复用，按有效长度入队。
  • 回声消除：Speex 改为定点运算。
  • 主页：界面已经拆掉时，不再因为测量连接按钮而闪退。
